Legend & column key

Trend arrows: ▲ last 30-day avg ≥ +2% vs prior 60-day avg · ▼ last 30-day avg ≤ -2% vs prior 60-day avg · — flat or insufficient history.

Set type colour key: Masterlise · Non-Masterlise · SMSP · 40th Anniversary. Grails are flagged with a 💎 next to the prize letter.

Prices: Mercari Japan and eBay show the rolling 3-month average sold price; MSRP is the original retail price. Switch the displayed currency (USD / JPY / EUR / GBP / AUD) with the picker at the top-right of the page — every price column converts in real time. Click 🔍 next to a Mercari or eBay price to open a fresh sold-listings search on that marketplace.

Prize Filter: ★ LOP shows only Last-One-Prize figures (the consolation prize for the last ticket in a sealed set); ★ Grail shows only the rare-value figures flagged with 💎. Toggling both shows the union.

Save figures: ★ on a row adds it to your Wishlist; ✓ marks it as Owned. Switch to the ★ Wishlist or ✓ Collection view (top-right of the filter strip) to see only your saved figures. Saved data lives in this browser only — use ↓ Export to back it up as a JSON file (the file contains only your save list) and ↑ Import on another browser to restore.

Set pages: click any Kuji set name (in the table or the set-header rows) to open a focused page for that set, with all its prizes plus an EV-per-ticket calculator comparing average secondary value to average MSRP.

Mercari Japan and eBay prices are read-only snapshots of recent sold-listing averages, not live data. BBTS cells link to the live product page when the figure is currently listed and otherwise show MSRP as plain text; cells without a recorded MSRP are left blank. Reference data originally compiled by Myk; figure-image catalogue courtesy of db-kuji.com.
